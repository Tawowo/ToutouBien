# Galerie de Mme Petitgand

Déposez ici les photos **authentiques** de l'activité (séances, balades, chiens accompagnés),
avec l'accord écrit des personnes reconnaissables et des propriétaires des chiens.

- Formats : `.jpg`, `.png`, `.webp` ou `.avif` (largeur conseillée ≥ 1600 px). Le site les optimise automatiquement.
- Légendes et textes alternatifs : complétez `src/content/galerie.json` avec le nom du fichier
  (ex. `{ "balade-parc.jpg": { "alt": "…", "legende": "…" } }`). Sans texte alternatif, la photo n'est pas affichée.
- La galerie apparaît d'elle-même sur la page « À propos » dès qu'une photo valide est présente.
- Ne jamais déposer ici une photo de banque d'images : la galerie est réservée aux photos réelles de l'activité.
